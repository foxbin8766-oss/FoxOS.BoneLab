FOX OS — Babylon.js WebXR Prototype 0.2

Purpose:
A PC-free prototype for testing FOX OS layout and VR interaction before building the real BONELAB/MarrowSDK version.

This version uses Babylon.js WebXR Default Experience Helper. Babylon's official documentation says this helper initializes XR, controllers, pointer selection, and teleportation, and supports floor meshes for teleportation.

Run:
1. Put index.html on an HTTPS static host.
2. Open it in the Meta Quest browser.
3. Use the Babylon.js XR/VR button.
4. Test the facility and report what should change.

Important:
- This is NOT a BONELAB pallet.
- Models are temporary procedural geometry.
- Babylon.js is loaded from its public CDN for this prototype. Babylon recommends self-hosting/pinning packages for production.
